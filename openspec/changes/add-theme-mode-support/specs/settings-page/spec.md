## MODIFIED Requirements

### Requirement: 账户域提供独立设置页承载核心设置分组
系统 SHALL 提供独立设置页作为账户级和应用级设置的统一承载位，并在同一页面中按“账户入口”“外观”“播放与缓存”“缓存明细”“音源”的顺序组织核心设置分组，而不是继续把这些能力散落在用户中心主内容区。设置页 SHALL 使用分组列表承载关键状态，让用户在对应分组内确认登录态、当前主题模式、默认音质、缓存占用和当前音源。

#### Scenario: 已登录用户进入设置页
- **WHEN** 系统已恢复有效用户会话且用户打开设置页
- **THEN** 系统展示独立设置页
- **AND** 页面先展示账户入口，再展示外观、播放与缓存、缓存明细和音源分组
- **AND** 账户入口展示当前登录用户的基础账户摘要与退出登录操作
- **AND** 外观、缓存和音源分组继续可见

#### Scenario: 游客态用户进入设置页
- **WHEN** 当前没有有效用户会话且用户打开设置页
- **THEN** 系统展示独立设置页
- **AND** 账户入口展示游客态或未登录状态
- **AND** 账户入口展示登录引导而不是退出登录操作
- **AND** 外观、缓存和音源分组继续可见

#### Scenario: 设置页分组展示关键状态
- **WHEN** 用户进入设置页
- **THEN** 账户入口展示账户状态
- **AND** 外观分组展示当前主题模式
- **AND** 播放与缓存分组展示默认音质和歌曲缓存上限
- **AND** 缓存明细分组展示总占用和分类占用
- **AND** 音源分组展示当前音源

#### Scenario: 用户选择主题模式
- **WHEN** 用户打开外观分组中的主题模式设置项
- **THEN** 系统展示“跟随系统”“日间模式”“夜间模式”三个单选项
- **AND** 当前已选模式具有明确选中状态
- **WHEN** 用户选择不同模式
- **THEN** 设置页将选择写入全局主题状态源
- **AND** 主题模式行更新为新的当前值
- **AND** 设置页立即按新模式重新渲染
